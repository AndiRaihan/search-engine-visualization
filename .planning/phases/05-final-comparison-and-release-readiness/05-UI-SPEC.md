## Layout & Interaction Contracts

### Element 1: Autoplay Slideshow ("Run All")

**Type:** Lesson advancement control trigger and background playback task.

**UI Presentation:**
- A "Run All" button is placed adjacent to the "Next step" button in the Lesson Panel navigation bar.
- Button Icon: Lucide `Play` (`play` svg) when idle.
- Button Text: "Run All"
- Visual separation from "Next step": `ml-md` (16px spacing).

**Autoplay Mechanics:**
- When clicked (or triggered by shortcut), the slideshow starts a playback interval.
- **Interval Delay:** `800ms` per step.
- **Advance Sequence:** The slideshow triggers the existing `nextStep` reducer action until it reaches the final step (`final-comparison`), where it automatically stops.
- **Cancellation:** If the user performs any of the following interactive events, autoplay is immediately cancelled and cleared, keeping the user on their current step:
  - Clicks "Previous step" button
  - Clicks "Next step" button
  - Clicks "Reset simulation" button
  - Selects a different Scenario from the dropdown list
  - Sets focus or enters input in the query input textbox or any document edit text area.
- **Reduced-Motion Bypass:** If `prefers-reduced-motion: reduce` is active in the user's browser, the slideshow completely bypasses the step-by-step 800ms delays. It instantly dispatches a transition to the final step (`final-comparison`) to prevent visual flashing and motion fatigue.

**Autoplay Aria & Liveness:**
- The Run All button has `aria-label="Run entire simulation sequence"` and `aria-live="polite"`.
- When active, screen readers receive a single announcement in the App-level live region: `"Autoplay started."` or `"Autoplay started. Bypassing steps because of reduced motion preference."`
- Intermediate step changes are **not** announced individually to prevent auditory overload.
- Upon completion, the focus is placed on the final comparison step heading, and the screen reader announces: `"Autoplay completed. Simulation finished at final comparison."`

### Element 2: Keyboard Navigation & Legend

**Shortcut Mapping:**
- **Previous Step:** `Alt` + `ArrowLeft`
- **Next Step:** `Alt` + `ArrowRight`
- **Run All:** `Alt` + `Shift` + `ArrowRight`

**Text Area Exclusions:**
- Keyboard event listeners must explicitly ignore these shortcut key combos if `document.activeElement` points to an editable field (i.e. `<textarea>` or `<input type="text">`), ensuring standard text navigation and typing operate without conflict.

**Visual Legend UI:**
- **Location:** Positioned inline, directly to the right of the navigation button group in the Lesson Panel.
- **Spacing:** `ml-lg` (24px left margin), separating it cleanly from buttons.
- **Style:** Compact notice panel:
  - Font size: `12px` (Label style).
  - Colors: `text-muted-text` (`#465766`), border-l-2 border-border-custom (`#AAB7BE`), `pl-sm` (8px padding).
  - Layout: `inline-flex items-center gap-xs`.
- **Copy:** `Shortcuts: Alt+← Previous | Alt+→ Next | Alt+Shift+→ Run All`
- **Aria Contract:** `aria-label="Keyboard shortcuts guide"`.

### Element 3: Side-by-Side Comparison Layout

**Grid Configuration:**
- Container CSS: `grid grid-cols-1 md:grid-cols-2 gap-lg` (24px gap).
- **Left Column:** Keyword Search Ranking (TF-IDF).
- **Right Column:** Semantic Search Ranking (dynamic label depending on the selected metric: "Euclidean Distance" or "Cosine Similarity").

**Row Interactivity:**
- Clicking a document row in either column highlights that document in **both** columns.
- **Synchronized Highlight Styles:**
  - Background: `bg-subtle-surface` (`#E7EEF0`).
  - Border: `border-2 border-accent-fill` (`#087F8C`).
  - Ring outline: `ring-2 ring-accent-fill/20` (`#087F8C` at 20% opacity).
  - Selected marker: A vertical `4px` accent bar (`bg-accent-fill`) is placed along the left edge of the row.
  - Non-selected state: `bg-secondary` (`#FFFFFF`), standard `border-border-custom` (`#AAB7BE`), `hover:bg-subtle-surface/50`.
- **Focus Order:** Rows are focusable (`tabIndex={0}`) and trigger selection on `Enter` or `Space` keys.

### Element 4: Rank Movement Cues

To ensure the rank difference between Keyword and Semantic rankings is readable without relying on color:

**Movement Math:**
- `Delta = Keyword Rank - Semantic Rank` (where Rank 1 is the top position).
- If `Delta > 0`: The document rank increased (moved up in semantic ranking compared to keyword).
- If `Delta < 0`: The document rank decreased (moved down in semantic ranking compared to keyword).
- If `Delta === 0`: The document rank remained unchanged.

**Visual Cues & Shapes:**
- The Semantic Column rows include a dedicated movement badge.
- The indicator uses unique text and symbols:

| Rank Change | Visual Shape | Text Delta | Visual Style |
|-------------|--------------|------------|--------------|
| **Rank Up** (e.g. +2) | Upward Triangle `▲` | `Moved up 2` | `text-accent-fill` (`#087F8C`) + bold |
| **Rank Down** (e.g. -1) | Downward Triangle `▼` | `Moved down 1` | `text-primary` (`#17212B`) + bold |
| **No Change** | Horizontal Dash `–` | `No change` | `text-muted-text` (`#465766`) + normal weight |

- **Spacing:** The shape is separated from the text delta description by `gap-xs` (4px).
- **Projector Safety:** Large font-bold text description ensures clear legibility under classroom projection conditions.

## Element 5: Mathematical Comparison Card

**Type:** Detailed inspection card appearing below the side-by-side ranking columns when a document is selected.

**UI Specification:**
- **Header:** `Detailed Comparison: D{index} ({title})`
- **Layout:** `grid grid-cols-1 md:grid-cols-2 gap-lg` inside a rounded card with border.
- **Left Column:** "Keyword Evidence (TF-IDF Contribution)"
  - Displays query term match statistics.
  - Lists matched terms with mathematical detail:
    - `"Term: {token} | TF: {tf_val} × IDF: {idf_val} = {tfidf_val}"`
  - Base formula summary: `"Total Keyword Score: Sum(TF-IDF) = {score_val}"`
- **Right Column:** "Semantic Evidence ({Active Metric Name})"
  - Consumes active metric selection (`euclidean` or `cosine`).
  - **Euclidean Mode Content:**
    - Shows coordinates: `Q({qx}, {qy})` and `D{index}({dx}, {dy})`.
    - Formula: `d = √((qx - dx)² + (qy - dy)²)`.
    - Calculations showing squared differences and square root: e.g. `√((0.60 - 0.55)² + (0.80 - 0.75)²) = √(0.0025 + 0.0025) = √0.005 = 0.071`.
    - Final result: `"Euclidean Distance = 0.071"` (accent color).
  - **Cosine Mode Content:**
    - Shows coordinates: `Q({qx}, {qy})` and `D{index}({dx}, {dy})`.
    - Formula: `sim = (Q · D) / (‖Q‖ × ‖D‖)`.
    - Calculation showing dot product and vector lengths.
    - Final result: `"Cosine Similarity = {sim_val}"` (accent color).

## Accessibility

### Non-Color Cues
- **Rank movement:** Indicated by unique character symbols (`▲`, `▼`, `–`) in addition to text labels ("Moved up 2").
- **Row selection:** A `4px` accent bar is rendered on the left border of the selected row in addition to the background color change.
- **Keyboard navigation legend:** Documented with plain text and clear keyboard arrows.

### Aria Attributes

| Element | Attribute | Value |
|---------|-----------|-------|
| Run All Button | `aria-label` | `"Run entire simulation sequence"` |
| Run All Button | `aria-live` | `"polite"` |
| Keyboard Legend | `aria-hidden` | `"true"` (avoid double-reading if instructions cover it) |
| Comparison Column List | `role` | `"listbox"` |
| Document Comparison Row | `role` | `"option"` |
| Document Comparison Row | `aria-selected` | `true` or `false` |

### Focus Management
- Keyboard shortcut `Alt+Shift+ArrowRight` starts autoplay. Focus remains on the controls.
- When autoplay finishes, focus is redirected to the `<h2>` header of the `final-comparison` page. The heading includes `tabIndex={-1}` to allow programmatical focus without visual outline.

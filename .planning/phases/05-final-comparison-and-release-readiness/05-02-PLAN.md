<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Global keyboard events -> app navigation | Keystrokes from the browser can trigger Previous, Next, or Run All. |
| Editable fields -> shortcut guard | Student typing in query/document fields must not unexpectedly navigate the lesson. |
| Run All -> focus/live region | Automatic completion changes focus and announces state to assistive technology. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04 | Tampering | Global keyboard handler | mitigate | Ignore events from editable targets and test that typing areas do not trigger navigation. |
| T-05-05 | Denial of Service | Run All behavior | mitigate | Use one tracked recursive timeout, clear it before rescheduling and on every cancellation path/unmount, and never allow multiple concurrent autoplay chains. |
| T-05-06 | Spoofing | Shortcut documentation | mitigate | Render shortcut legend beside actual controls and keep button accessible names aligned with handlers. |
| T-05-SC | Tampering | npm package supply chain | mitigate | No package-manager install tasks are part of this plan. |
</threat_model>

## Phase Goal

**As a** high school student, **I want to** follow a complete keyword-search lesson from tokenization to explained TF-IDF ranking, **so that** I can explain how each visible calculation changes the result order.

<objective>
Turn the existing Phase 1 visualization preview into live tokenization, matching, term-frequency, and inverse-document-frequency teaching steps using the single snapshot from Plan 02-01.

Purpose: Give students a coherent first half of the keyword journey where every visible token, count, formula input, and importance label updates immediately after source edits.
Output: Four projector-readable keyword views, one memoized App-level snapshot integration, and Wave 0 component coverage.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Editable session to React DOM | Untrusted query and document text is rendered as tokens, card text, and summaries. |
| Keyword snapshot to visualization router | Derived numeric/string evidence selects and populates four teaching views. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | `TokenizationStep`, `MatchingStep` | mitigate | Render values only as React text/elements; prohibit `dangerouslySetInnerHTML`, string-built markup, dynamic event attributes, and unsafe URL contexts; include literal-markup DOM tests. |
| T-02-02 | Denial of Service | `App`, all foundation steps | mitigate | Compute one memoized snapshot in App and pass it down; components only map finite precomputed arrays and never rerun tokenization or formulas. |
| T-02-04 | Information Disclosure | visible source text | accept | The app intentionally displays user-entered classroom text locally; it sends no data to a backend or third party. |
| T-02-SC | Tampering | npm supply chain | accept | This plan installs or upgrades no packages and reuses existing React, Lucide, and local shadcn primitives. |
</threat_model>

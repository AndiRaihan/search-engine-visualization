<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Student text -> React visualization | Query/document edits are untrusted strings rendered into the semantic UI. |
| Scenario vectors -> semantic math/SVG payload | Static numeric vectors become labels, distances, rankings, and later SVG metadata. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | `SemanticVisualizationSteps.tsx` text rendering | mitigate | Render edited query/document text only as normal React text nodes; add sanitization regression in Task 1; do not use `dangerouslySetInnerHTML`. |
| T-03-02 | Spoofing | `SemanticSnapshot` point labels | mitigate | Derive visible labels and later accessibility labels from the same `SemanticPoint` objects, not duplicated strings. |
| T-03-03 | Denial of Service | Euclidean breakdown display | mitigate | Build equations from fixed numeric vectors and formatted numeric strings, not unbounded edited text. |
| T-03-SC | Tampering | npm package supply chain | mitigate | No package-manager install tasks are part of this plan; if a package install becomes necessary, stop for Package Legitimacy Audit. |
</threat_model>

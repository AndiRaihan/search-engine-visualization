## Trust Boundaries

| Boundary | Description |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-07 | Spoofing | `MeaningMap` distance lines | mitigate | Lines and textual rows both derive from `semanticSnapshot.distanceRows`; tests compare line count to document count. |
| T-03-08 | Tampering | `EuclideanBreakdownPanel` formulas | mitigate | Render equations from fixed numeric vector values and domain-provided breakdown fields; do not interpolate edited text into equations. |
| T-03-09 | Denial of Service | Ranking selection UI | mitigate | Use at most local document count from static scenarios; no backend calls, recursion, or unbounded rendering. |
| T-03-SC | Tampering | npm package supply chain | mitigate | No package-manager install tasks are part of this plan; native SVG and current dependencies are sufficient. |
</threat_model>

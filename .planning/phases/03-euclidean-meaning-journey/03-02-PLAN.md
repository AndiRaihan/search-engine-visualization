<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Student text -> keyword-limitation list | Edited query/document text can appear near keyword-score and synonym explanations. |
| Semantic snapshot -> SVG accessibility metadata | Visible SVG labels and assistive text must describe the same points. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | Tampering | `KeywordLimitationStep` document rendering | mitigate | Render document titles/text as React text nodes; preserve test that hostile HTML does not create DOM script/image execution surfaces. |
| T-03-05 | Spoofing | `MeaningMap` SVG labels and table | mitigate | Use `semanticSnapshot.points` as the single source for visible labels, SVG titles/descriptions, and table rows. |
| T-03-06 | Information Disclosure | `Switch Scenario` action | accept | The app has only local public teaching scenarios and no private data or backend request. |
| T-03-SC | Tampering | npm package supply chain | mitigate | No package-manager install tasks are part of this plan; keep native SVG and existing lucide-react. |
</threat_model>

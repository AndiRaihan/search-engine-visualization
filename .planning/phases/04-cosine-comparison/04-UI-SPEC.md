## Layout & Interaction Contracts

### Phase 4 New Elements

This phase adds three new visual elements and modifies two existing surfaces:

| # | Element | Location | Triggers |
|---|---------|----------|----------|
| 1 | **Semantic Metric Toggle** | Visualization Panel, top-right, above step body | Visible on `semantic-ranking` and `final-comparison` steps only |
| 2 | **Cosine Origin Rays** | SVG Meaning Map | Visible when `semanticMetric === 'cosine'` AND step is `meaning-vectors` or `semantic-ranking` |
| 3 | **Cosine Breakdown Panel** | Semantic Ranking step, below ranking list | Visible when a document is selected AND `semanticMetric === 'cosine'` |

### Element 1: Semantic Metric Toggle

**Type:** Segmented control (two adjacent buttons with shared border)

**Visibility gate:**
```
IF activeStepId IN ('semantic-ranking', 'final-comparison') THEN render toggle
ELSE render nothing
```

**Appearance:**
- Two buttons grouped with no gap between them
- Outer container: `border border-border-custom rounded-[8px] overflow-hidden`
- Active button: `bg-accent-fill text-accent-contrast font-bold` (text-size: 14px)
- Inactive button: `bg-secondary text-muted-text font-normal hover:bg-subtle-surface/50` (text-size: 14px)
- Minimum touch target: 44px height (consistent with existing interactive elements)
- Button internal padding: `px-md py-sm` (16px horizontal, 8px vertical)

**Interaction model:**

| Event | Behavior |
|-------|----------|
| Click Euclidean button | Sets `semanticMetric = 'euclidean'` via dispatch |
| Click Cosine button | Sets `semanticMetric = 'cosine'` via dispatch |
| Keyboard: Tab | Focus moves to toggle group, then first button, then second button |
| Keyboard: Left/Right arrows | Move focus between Euclidean ↔ Cosine buttons within group |
| Keyboard: Enter/Space | Activates focused button |
| Hover (inactive) | `bg-subtle-surface/50` transition |
| Focus-visible | `ring-4 ring-accent-fill/20` on focused button |
| Reduced motion | `transition-none` (per global `prefers-reduced-motion` rule) |

**Aria contract:**
- Container: `role="group" aria-label="Semantic metric"`
- Euclidean button: `aria-pressed={semanticMetric === 'euclidean'}`
- Cosine button: `aria-pressed={semanticMetric === 'cosine'}`
- Screen reader announcement on toggle: Live region: "Semantic metric switched to [euclidean distance / cosine similarity]."

**Persistence:** Toggle state survives step navigation (backed by reducer `semanticMetric` field per D-02).

### Element 2: Cosine Origin Rays

**Type:** Native SVG `<line>` elements overlaid on the existing Meaning Map

**Visibility:**
- Euclidean mode: **hidden** (only existing query→document distance lines visible)
- Cosine mode: existing distance lines **hidden**, origin rays **visible**
- The `showDistanceLines` prop does NOT toggle origin rays — the metric state controls both

**Visual specification:**

| Ray | From | To | Stroke | Width | Dash | Opacity |
|-----|------|----|--------|-------|------|---------|
| Query origin ray | `(0, 0)` mapped to SVG coords `(60, 440)` | Query point `(toSvgX(qx), toSvgY(qy))` | `#AAB7BE` | 1px | `4,4` | 70% |
| Document origin rays | `(0, 0)` mapped to SVG coords `(60, 440)` | Each document point `(toSvgX(dx), toSvgY(dy))` | `#AAB7BE` | 1px | `4,4` | 50% |

**Origin point calculation:**
- The origin `(0, 0)` in semantic space maps to SVG coordinates via the existing mapping functions:
  - `toSvgX(0) = 60` (paddingLeft)
  - `toSvgY(0) = 440` (paddingTop + chartHeight)

**Rendering order (z-index in SVG):**
1. Grid lines (existing)
2. Axis lines (existing)
3. **Origin rays** (new — below points so they don't obscure labels)
4. Distance lines (existing — hidden in cosine mode)
5. Points (query star, document circles)
6. Labels (existing)

**SVG description update:** When in cosine mode, add to `<desc>`: "The dashed lines from the origin represent direction vectors. Cosine similarity measures how close these directions are, regardless of magnitude."

**Zoom/Pan compatibility:** Origin rays live inside the existing `transform="translate(pan.x, pan.y) scale(zoom)"` group. Per D-05, zoom and pan are unchanged.

### Element 3: Cosine Breakdown Panel

**Type:** Card component with two-column formula grid (extending existing `EuclideanBreakdownPanel` pattern)

**Visibility:**
- Euclidean mode: `EuclideanBreakdownPanel` shown (existing behavior)
- Cosine mode: `CosineBreakdownPanel` shown (new)
- Panel only renders when a document is selected

**Layout specification:**

Card header: "Cosine Similarity Calculation for D{docIndex} ({title || 'Untitled'})"

Grid layout (same pattern as Euclidean breakdown):

| Row Label | Display Format | Source |
|-----------|---------------|--------|
| Formula: | `sim(Q, D₁) = (Q · D₁) / (‖Q‖ × ‖D₁‖)` | Formatted via existing `formatMath()` helper |
| Dot Product: | `(qₓ × dₓ) + (qᵧ × dᵧ) = (0.60 × 0.55) + (0.80 × 0.75) = 0.330 + 0.600 = 0.930` | Substituted with actual values |
| Query Length ‖Q‖: | `√(0.60² + 0.80²) = √(0.360 + 0.640) = √1.000 = 1.000` | Calculated from query vector |
| Document Length ‖D₁‖: | `√(0.55² + 0.75²) = √(0.303 + 0.563) = √0.866 = 0.931` | Calculated from document vector |
| Final Similarity: | `sim = 0.930 / (1.000 × 0.931) = 0.930 / 0.931 = 0.998` | Final computed value in accent color + bold |

**Grid specification:**
- CSS: `grid grid-cols-[140px_1fr] gap-x-md gap-y-sm`
- Left column: `text-muted-text font-bold` (row label)
- Right column: `font-mono bg-subtle-surface/50 px-sm py-xs rounded` (formula/value)
- Final row: `text-accent-fill font-bold font-mono bg-subtle-surface/50 px-sm py-xs rounded`

**Zero-vector guard:** Per D-07, if either vector magnitude is zero, display the breakdown with `0.000` for both the magnitude and final similarity, and annotate: "(Zero-length vector — similarity is 0.000)"

### Element Modifications to Existing Surfaces

#### SemanticRankingList (line items)
- Euclidean mode: Score label reads `Distance: 0.141` (existing)
- Cosine mode: Score label reads `Similarity: 0.998` (new)
- Rank 1 label: Euclidean → "Rank 1 (Closest)", Cosine → "Rank 1 (Most Similar)"
- Last rank label: Euclidean → "Rank N (Furthest)", Cosine → "Rank N (Most Dissimilar)"

#### DistanceTable → becomes MetricTable
- Column header: Euclidean → "Distance", Cosine → "Similarity" (metric-aware)
- Component may be renamed to `SemanticMetricTable` but must accept same data

#### lessonSteps.ts (step descriptions)
- `semantic-ranking` step description becomes metric-aware:
  - Euclidean default: "This step measures the straight-line distance..."
  - Cosine: "This step measures the cosine similarity (angle) between direction vectors..."

#### Meaning Map SVG `<desc>`
- Euclidean: existing desc (unchanged)
- Cosine: updated to describe origin rays and cosine angle interpretation

### Cosine Breakdown Selection Persistence

Per research Pitfall 4 and assumption A1: When the user toggles metrics, **preserve the currently selected document**. The breakdown panel switches content (Euclidean ↔ Cosine) but remains focused on the same document. If the selected document no longer exists in the ranked list, fall back to showing the first-ranked document.

### Keyboard Navigation (Phase 4 additions)

| Key | Context | Action |
|-----|---------|--------|
| Tab | Visualization Panel | Focus moves through: step heading → metric toggle group → meaning map → ranking list → breakdown panel |
| ← / → | Within toggle group | Move focus between Euclidean ↔ Cosine buttons |
| Enter / Space | Focused toggle button | Activate that metric |
| ↑ / ↓ | Ranking list | Move selection between ranked items |
| Enter | Meaning map document point (focused) | Select that document for breakdown |

### Reduced Motion

Per existing global rule in `src/index.css`:
```css
@media (prefers-reduced-motion: reduce) {
  * { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; }
}
```

Phase 4 elements must respect this:
- Toggle button transition: `transition-colors motion-reduce:transition-none` on hover/active changes
- Origin ray appearance/disappearance: instant (no animation)
- Panel content swap: instant on toggle (no crossfade)

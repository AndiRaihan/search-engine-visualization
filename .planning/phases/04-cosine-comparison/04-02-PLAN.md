<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UI controls -> reducer state | User clicks or keyboard actions change the active metric. |
| Reducer metric -> semantic snapshot -> visual evidence | Active metric determines ranking order, labels, map overlays, and selected breakdown. |
| Editable text -> rendered UI | Student query/document edits appear near explanations and must remain text, not markup. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-04 | Spoofing | `SemanticRankingStep` labels and explanations | mitigate | Derive displayed metric label, score, and ordering copy from the active semantic snapshot; tests assert Distance vs Similarity text. |
| T-04-05 | Tampering | `VisualizationPanel` toggle | mitigate | Use reducer-backed `semanticMetric` and `aria-pressed`; tests verify step navigation does not reset selected metric or source data. |
| T-04-06 | Denial of Service | `MeaningMap` overlays | mitigate | Render at most one line per local point and keep all lines inside existing zoom-pan group; no unbounded loops or remote calls. |
| T-04-07 | Tampering | Edited query/document text near ranking evidence | mitigate | Continue rendering user input as React text children and preserve existing XSS regression tests. |
| T-04-SC | Tampering | npm package supply chain | mitigate | No package-manager install tasks are part of this plan; use existing React, Vitest, shadcn components, and native SVG only. |
</threat_model>
